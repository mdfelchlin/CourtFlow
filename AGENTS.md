# CourtFlow agent guide

New product work starts at [`intent/product/intent.md`](intent/product/intent.md). Read [`intent/README.md`](intent/README.md) for how artifacts move: accepted `intent.md`, then `spec.md` in the same folder, then `plan.md`, then code outside `poc/`. Project skills for those steps live in [`.cursor/skills/`](.cursor/skills/): `capture-intent`, `write-spec`, and `write-plan`.

[`poc/`](poc/) is a proof of concept. Do not extend it unless the user asks to patch the reference app. Domain language for now is [`poc/CONTEXT.md`](poc/CONTEXT.md). Behavior and screen detail live under [`poc/docs/`](poc/docs/).
