# CourtFlow agent guide

New product work starts at [`intent/product/intent.md`](intent/product/intent.md). A new slice starts in its own worktree with `start-intent`. Read [`intent/README.md`](intent/README.md) for how artifacts move: draft `intent.md`, then an accepted `intent.md`, then `spec.md` in the same folder, then `plan.md`, then code under [`src/`](src/). Project skills for those steps live in [`.cursor/skills/`](.cursor/skills/): `start-intent`, `capture-intent`, `write-spec`, and `write-plan`.

Domain language lives in the accepted product intent and the accepted specs.
