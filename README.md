# CourtFlow

CourtFlow is being rebuilt from [`intent/product/intent.md`](intent/product/intent.md). That file is the north star: what the application is, who it is for, the tech stack, and the pillars of value.

New work starts in [`intent/`](intent/README.md). An accepted intent is followed by a spec, then a plan, then code under `src/`.

Start the local API, Blazor app, and Postgres with `dotnet run --project src/CourtFlow.AppHost` from the repository root.
