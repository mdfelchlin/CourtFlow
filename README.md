# CourtFlow

CourtFlow is being rebuilt from [`intent/product/intent.md`](intent/product/intent.md). That file is the north star: what the application is, who it is for, the tech stack, and the pillars of value.

The previous app, its docs, and its CI/CD workflows are a proof of concept under [`poc/`](poc/). Read [`poc/README.md`](poc/README.md) to run that app locally. Pushes no longer build or deploy it. GitHub Actions only runs workflows from the repository root, and this root has none yet.

New work starts in [`intent/`](intent/README.md). An accepted intent is followed by a spec, then a plan, then code outside `poc/`.
